# Projet de découverte

## Description
Bienvenue dans ce projet de découverte. Ce dépôt sert de base pour apprendre la structure d’un projet, la rédaction d’un README et la gestion des fichiers.

## Objectifs
- Comprendre la structure d’un dépôt Git
- Rédiger une documentation claire
- Mettre en pratique les bases du développement

## Exemple
Voici un texte de démonstration :

**Projet :** TP1 - Découverte

*Le but est d’apprendre et d’expérimenter.*
